# Project preferences

- The official project name is Street-View Geolocation Transformer (S.V.G.T.).
- The distributed prediction client must let users select and remember a local model file path, with Chinese and English UI support.
- Distribution archives must never include model weights (including `.pt`, `.pth`, `.ckpt`, `.safetensors`, `.onnx`, or equivalent weight files). Distribute models separately. Exclude local environments, caches and personal preferences from archives.
