# Geographic reference data

The training data collector uses country and territory polygons from UN Geospatial / OCHA FISS and US state boundaries from the US Census TIGERweb. The [UN source metadata](maps/un_map_sources.json) preserves the original usage notes. The reference geometries support geographic filters for Mapillary collection. They carry no implied endorsement of boundaries or territorial status.

- [UN Geospatial / OCHA reference service](https://gis.unocha.org/server/rest/services/Hosted/Global_AB_25M_simplified_fs_gray/FeatureServer)
- [US Census TIGERweb](https://tigerweb.geo.census.gov/arcgis/rest/services/TIGERweb/State_County/MapServer/0)
