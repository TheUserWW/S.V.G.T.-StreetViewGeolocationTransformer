# S.V.G.T. 地图纠错与即时学习

开发版 `Prediction.bat` 支持在每次预测后，用游戏公布的真实位置立即更新个人模型。当前版本只更新定位头，视觉主干保持固定。它是基于人工真值的在线适配，不保证每次更新都提高新地点的准确率。

## 使用

1. 重启开发版预测地图，选择基础模型（例如 V4），导入自己的游戏街景并预测。
2. 游戏公布真实位置后，放大本地地图，点击 **点选真值并学习**，再在地图上点击实际位置。普通地图点击不训练；再次点击按钮可取消点选。
3. 后台立即执行少量更新并保存个人模型。界面自动选择该模型，下一次预测开始使用。当前地图保留的是更新前结果，不能把本张图片的学习后效果当作独立测试成绩。
4. 误点时点击 **撤销上次学习**。第一次更新可切回基础模型；后续更新保留一个原子保存的上一版本。需要更早版本时，请自行备份并通过模型路径选择。

CPU 和 CUDA 均可用。速度取决于设备、模型加载和保存时间；一次点选不是零延迟的推理操作。学习与预测、解释、全量评估互斥，关闭窗口会等待本次保存完成。

## 保存内容

默认位于 `.gui/online_learning/<会话>/personal.pt`；自定义设置文件时保存在该设置目录的 `online_learning/` 下。个人模型包含完整推理权重、基础模型位置/文件标记、更新次数和最多 256 个历史地点的特征、真值坐标及图片路径/哈希。不会复制原图。重复提交同一组图片会替换其记忆标签，不增加重复地点；再次学习仍会执行新的更新。

定位头默认每次更新 4 步、学习率 `1e-5`，同时轮流回放最多 8 个历史地点。新纠错与历史回放各占一半损失权重。最初尚无历史时，仅有本次标注参与。视觉主干冻结，因此保存的历史特征与当前视觉编码保持一致。记忆有容量限制，回放不能保证完全避免遗忘，也没有旧 OSV 数据的自动全局回放或独立质量门禁。

基础模型文件不会被覆盖；下一次启动会记住当前选择的个人模型。个人模型可以移动后用于推理，但继续即时学习要求它留在原路径，避免将特征记忆与另一个学习会话混淆。个人模型是推理权重，不是离线训练的完整优化器断点；需要开启新的 OSV 阶段时使用 `--init-from`。

## 数据与评估

使用实际位置作为反馈，不能把模型自己的预测坐标当作训练标签。错误坐标会强化错误。对于局部区域反复出现的相似画面，应同时保留其他地域的独立评估。

随机 official test 模式禁止学习，已知 `OpenStreetView-5M/test` 与 `images/test` 路径也被后端拒绝。不要手动复制、改名测试图片后用于学习；学习过的地点和拍摄序列不能再视为独立测试。离线 OSV 训练原有的数据检查不变，人工纠错通过独立入口处理，不冒充 OSV 元数据。

这项功能目前属于开发版预测地图。分发客户端继续支持中英文及自选模型路径，可以推理个人模型，但没有即时学习控件。分发压缩包仍不包含任何权重、个人学习记录或偏好；模型另行提供。
